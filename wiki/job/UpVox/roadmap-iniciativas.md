# Roadmap / Iniciativas Planejadas

Índice dos specs/plans (`docs/superpowers/{specs,plans}/`) encontrados nos 3 repos do UpVox — cada iniciativa tem um par `<slug>.md` (plano) + `<slug>-design.md` (design). Datas são de quando o doc foi escrito, não de conclusão; nenhum foi lido por completo, isto é só um índice para saber o que já foi pensado antes de reabrir a discussão.

## upvox-api
Auth+Users, Content (courses/modules/lessons), Social module, design geral Course/Plan/Tool/Vox, Plans, Stripe, Voxes, Sales analytics, SOLID/DI baseado em classes, API Gateway, cache Redis do catálogo, admin de faturas com falha, estorno de assinatura, `/me` invoices com falha, access roles & permissions, analytics de caixa, fix de race condition webhook→invoice, criação de usuários staff/admin, observabilidade (Sentry).

## profissao_laser (front)
Product add-ons, produtos agrupados, integração de créditos Vox, permissões na API de cursos, campos de falha em pagamentos.

Docs de rotas/gaps avulsos (sem par plan/design): gaps API↔front (`API_GAPS*.md`), agendamentos, comunidade (geral, eventos, [[wiki/job/UpVox/comunidade-vitrine-projetos|projetos]]), chat de dúvidas, dúvidas/avaliações de lição, progresso de lição, lições salvas, biblioteca de vetores, vetorização, [[wiki/job/UpVox/fabrica-de-ferramentas|Fábrica de Ferramentas]].

## Profissao-Laser-API (main API antiga)
Sistema de créditos, cache Redis da comunidade. Docs avulsos: modo "só curso", variáveis de ambiente de provisionamento.
