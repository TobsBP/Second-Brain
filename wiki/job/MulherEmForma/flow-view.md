# flow-view (Quiz Flow Visualizer)

Ferramenta interna (React + reactflow + dagre) para visualizar a lógica de um quiz/XRay como um diagrama de fluxo interativo, com exportação em PDF. Não é consumida pelo app — é uma ferramenta de debug/design para a equipe.
