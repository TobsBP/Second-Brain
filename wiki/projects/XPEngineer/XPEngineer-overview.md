# XP Engineer

Plataforma gamificada de aprendizado de engenharia, estética "Precision-Play". Caminho de aprendizado dinâmico (matemática básica → integridade estrutural), sistema de XP/progressão de nível, perfil especializado.

## Topics covered so far
- Arquitetura dos 3 serviços: API, app do aluno (easy-eng), painel admin.
