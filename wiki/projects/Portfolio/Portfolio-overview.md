# Portfolio

Site de portfólio pessoal.

## Stack
Next.js 16 (App Router), TypeScript 5, Tailwind CSS v4, React Icons, Biome, Husky + lint-staged, CI/CD via GitHub Actions.

## Páginas
`/` (hero com snippet animado), `/projects`, `/about` (timeline + fun facts), `/knowledge` (stack técnico), `/contact`.

Dados centralizados em `src/data/` (`projects.ts`, `technologies.ts`, `certificates.ts`, `heroCode.ts`), separando conteúdo de apresentação.
