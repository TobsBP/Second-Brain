## README
"Quiz Flow Visualizer — aplicação React para visualizar a lógica complexa de um quiz a partir de uma fonte de dados, num diagrama de fluxo interativo." Mapeia perguntas, respostas e os caminhos de ramificação. Usa `reactflow` para renderizar o grafo, `dagre` para layout automático, e permite exportar a visualização como PDF.

## Observação
Ferramenta interna para visualizar o fluxo de quizzes/XRay (avaliação) — não é consumida pelo app, é uma ferramenta de debug/design para a equipe.
