Levantamento a partir de `~/Documents/projects/portfolio/`.

## O que é
Site de portfólio pessoal.

## Stack
Next.js 16 (App Router), TypeScript 5, Tailwind CSS v4, React Icons, Biome, Husky + lint-staged, CI/CD via GitHub Actions.

## Páginas
`/` (hero com snippet de código animado), `/projects` (portfólio de projetos com badges de tecnologia), `/about` (perfil, timeline de carreira, fun facts), `/knowledge` (stack técnico visualizado), `/contact`.

## Estrutura
`src/data/` centraliza os dados exibidos (`projects.ts`, `technologies.ts`, `certificates.ts`, `heroCode.ts`) — separando conteúdo de apresentação.
